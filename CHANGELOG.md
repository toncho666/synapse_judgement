# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/),
и этот проект придерживается [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-02-20

### Added
- Frontend приложение на React + TypeScript + Tailwind
- Backend API на Node.js + Express + Prisma
- PostgreSQL база данных
- JWT аутентификация
- 5 AI агентов (Technical, Fundamental, Portfolio, News, Earning Calls)
- Агент-Судья для синтеза вердиктов
- Система авторизации и регистрации
- Личный кабинет пользователя
- Лидерборд
- Реферальная программа
- Система достижений
- Тарифные планы (Free, Pro, Enterprise)
- Детальные страницы агентов
- Примеры отчётов с визуализациями
- Полная документация

### Features
- Мгновенное обновление цен при выборе агентов
- Прозрачная система оплаты
- Адаптивный дизайн
- Apple-inspired UI
- Анимации и микро-взаимодействия
- Логирование всех операций
- Обработка ошибок
- Валидация данных

---

## Типы изменений

- `Added` - новые функции
- `Changed` - изменения в существующем функционале
- `Deprecated` - функции, которые будут удалены
- `Removed` - удалённые функции
- `Fixed` - исправления багов
- `Security` - исправления безопасности

---

## Версионирование

- **Major** (x.0.0) - несовместимые изменения API
- **Minor** (0.x.0) - добавление функционала обратно совместимо
- **Patch** (0.0.x) - исправления багов обратно совместимо
