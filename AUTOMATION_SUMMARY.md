#### Новые файлы:

## 🔧 Настройка

### 1. Получите API ключ

Перейдите на https://www.alphavantage.co/support/#api-key

**Бесплатный лимит**:
- 5 запросов/мин
- 500 запросов/день
- Данные с задержкой 15 минут

### 2. Добавьте ключ в .env

```bash
cd backend
echo 'ALPHA_VANTAGE_API_KEY="ваш_ключ_здесь"' >> .env
```

### 3. Перезапустите backend

```bash
cd backend
npm run dev
```

Вы должны увидеть:
```
🚀 Starting background stock updates (every 60 minutes)
📊 Fetching stock data...
✅ Fetched 11 stock quotes
```

### 4. Проверьте работу

```bash
curl http://localhost:3001/api/stocks
```

Откройте http://localhost:5173 - лента котировок показывает реальные данные!

## 🎨 Особенности реализации

### ✅ Без сохранения в БД
- Данные кэшируются в памяти
- Быстрый доступ
- Нет нагрузки на БД

### ✅ Fallback механизм
- При ошибке API используются мок-данные
- Пользователь всегда видит данные
- Плавная работа даже без интернета

### ✅ Rate limiting
- 200ms задержка между запросами
- Соблюдение лимитов API
- Защита от блокировки

### ✅ Автоматизация
- Фоновое обновление без участия пользователя
- Автоматический старт при запуске сервера
- Настраиваемый интервал обновления

## 📈 Производительность

### Запросы к API:
- **11 символов** × **24 раза/день** = **264 запроса/день**
- **Лимит Alpha Vantage**: 500 запросов/день ✅
- **Запас**: 236 запросов/день

### Время ответа:
- **Из кэша**: < 10ms
- **С обновлением**: ~2-3 секунды (11 запросов)

### Память:
- **Кэш**: ~1 KB (11 котировок)
- **Нагрузка**: Минимальная

## 🛠️ Настройка

### Изменить список акций

Откройте `backend/src/services/stock.service.ts`:

```typescript
const TRACKED_SYMBOLS = [
  'AAPL', 'NVDA', 'MSFT', 'TSLA', 'AMZN', 
  'GOOGL', 'META', 'S&P 500', 'NASDAQ', 'BTC', 'ETH'
];
```

### Изменить интервал обновления

В том же файле:

```typescript
const CACHE_DURATION = 60 * 60 * 1000; // 1 час
```

### Изменить частоту обновления на frontend

В `frontend/src/hooks/useStocks.ts`:

```typescript
// Refresh every 5 minutes
const interval = setInterval(fetchStocks, 5 * 60 * 1000);
```
